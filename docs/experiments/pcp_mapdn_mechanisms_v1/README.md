# Fixed-MAPPO communication comparison v1

This is a fresh comparison of project communication modules, with a common BenchMARL MAPPO training procedure within each task. It is not a reproduction tournament among complete CommNet, IC3Net, TarMAC, or DGN systems. Encoder width 128, two Tanh layers, one communication round, clean instantaneous delivery, no role embeddings, and task-specific existing centralized critics remain fixed. PCP's scripted prey, reward, physics, corrected RNG and observation semantics are unchanged. MAPDN's critic uses concatenated zone-local observations; it is not given a new full physical state.

Core is **90**, or **115** with both explicitly selected supplements. Core collection is 36,000,000 PCP + 3,932,160 MAPDN frames. Qualification adds 2,400,000 + 262,144; engineering smokes add 72,000 + 3,072. Supplements append rows after the core. More training seeds can be declared for the entire suite before collection; duplicate/overlapping stage namespaces are rejected.

Final evaluation is exactly 600k or 131,072, never best-on-test. PCP retains 120k/240k/360k/480k/600k native files; MAPDN retains 32,768/65,536/98,304/131,072. Cleanup retention is explicitly unlimited for this small mandatory schedule. Both native actor/critic state and managed final actors must agree. Actor-only checkpoints are not exact resume points.

Each final policy has deterministic live and fully severed arms with independent evolving trajectories from paired reset conditions. PCP uses 256 episodes of 100 steps, yielding **30,720 primary episodes / 3,072,000 transitions** across the core. MAPDN uses 16 windows of 239 transitions, yielding **960 trajectories / 229,440 transitions**. The suite repeats each complete paired result for exact replay, doubling that final evaluation compute without increasing independent scientific sample counts. Validation, random audits, normalization and strict reconstruction add further work.

The primary PCP outcome is first rewarded contact at or before transition 50. Contacts at 49 and 50 count; 51 does not. Noncontacts retain censoring at the horizon, and all episodes retain the full task horizon. Predator-group return is kept separate from the prey group's opposite return. Secondary metrics include contact time/duration/pairs, collisions, boundaries, distances and visibility opportunities.

The primary MAPDN outcome is mean voltage violation in p.u.: `max(0.95-v,0)+max(v-1.05,0)` averaged over the adapter's observed bus population. Integer violating-bus counts, observed and attempted transition counts, mean absolute reactive effort (MVAr), total line loss (MW), native return, solver failures, saturation and curtailed PV remain separate. Team diagnostics are counted once per transition. Observed voltage means are conditional on valid physical solutions; failed or incomplete physical banks prevent a clean voltage ranking. Solver success is not grid safety. Real bus/inverter identities and physical feeder tables are exported at preflight. [MAPDN paper](https://proceedings.neurips.cc/paper/2021/hash/1a6727711b84fd1efbb87fc565199d13-Abstract.html)

PCP banks use distinct training/development/random-audit/test namespaces. MAPDN uses chronological 60/20/20 blocks, full history/terminal footprint exclusions, 16 training-only normalizer windows, 8 qualification-validation, 8 main-validation, and 16 test windows. One normalizer and training-derived inverter capacity are shared across all methods. Bank creation records test identifiers but never rolls out their trajectories before both core training closures. All available historical declaration files are audited; unavailable older evidence is labeled unavailable, not presumed nonoverlapping.

Four method-versus-Identity contrasts in each of three conditions are the 12 primary descriptive effects. Positive means better: contact(method)−contact(Identity), or voltage(Identity)−voltage(method). LocalCapacity and Broadcast comparisons are separate; PCP information interactions subtract global-visibility benefits from restricted-visibility benefits. Reliance uses live−severed contact or severed−live voltage, separately from learning benefit. Episodes are averaged within policy first. A fixed PCG64 RNG, seed 3,900,000 and 10,000 shared training-seed resamples produce descriptive pointwise 95% intervals. Five training seeds do not guarantee power; intervals are not simultaneous across 12 contrasts, and crossing zero does not establish equivalence. Missing/numerically failed rows stay in the requested denominator. [Statistical evaluation](https://arxiv.org/abs/2108.13264)

Identity is parameterless at the communication slot but its actor learns. LocalCapacity32 adds 8,192 active local projection parameters with no cross-agent dependence. Broadcast has 8,192, Gated 8,321, Attention 16,384, and Graph 16,416 under these settings. LocalCapacity64 adds 16,384 active projection parameters. No dormant branch is counted as active local capacity. The 32-wide control exactly matches basic Broadcast projections, not every mechanism's computation. Actual per-group actor/critic and branch counts are retained; PCP prey parameters are separate. [Capacity/bandwidth context](https://arxiv.org/abs/2605.21085)

Broadcast/Gated use 32-scalar float32 payload equivalents. Attention/Graph use key+value payloads totaling 64 scalars; local queries are not transmitted. Emitted packets and directed receiver deliveries are separate costs. Small soft gates do not remove packets. Headers, contention and actual transport infrastructure are not modeled. Project adaptation sources: [CommNet](https://arxiv.org/abs/1605.07736), [IC3Net](https://arxiv.org/abs/1812.09755), [TarMAC](https://proceedings.mlr.press/v97/das19a.html), [DGN](https://arxiv.org/abs/1810.09202), [GATv2](https://arxiv.org/abs/2105.14491). Algorithm/framework sources: [BenchMARL](https://www.jmlr.org/papers/v25/23-1612.html), [MAPPO](https://arxiv.org/abs/2103.01955).

Message activity, attention patterns, or action changes alone do not establish benefit. Removal reliance includes an input distribution shift and is not a separately retrained no-message policy. Negative, equal or inconclusive effects are valid. No communication necessity, convergence, broad algorithm ranking, memory impossibility, physical safety or feeder-transfer conclusion follows from this allocation. [Communication measurement pitfalls](https://arxiv.org/abs/1903.05168), [scope of reasoning and memory claims](https://arxiv.org/abs/2602.20804).

The optional topology supplement uses in-service electrical paths, maps inverter agents to buses, constructs symmetric-union electrical-hop k-nearest neighbors (`k=min(2,N-1)`), and fixes deterministic index tie-breaking. It preserves the physical feeder. Each seed gets a predeclared degree/edge/connectivity-matched random graph with bounded attempts to find a distinct control. Degenerate/unavailable topology is blocked, never relabeled full/random. Run the core without this supplement if real mapping cannot be validated.
