# SoftRole-HetGAT research

Start with the **[feasibility report (PDF)](SOFTROLE_FEASIBILITY_REPORT.pdf)** or its **[editable Markdown source](SOFTROLE_FEASIBILITY_REPORT.md)**.

The report assesses learned role and communication recovery under changing team membership and physical capabilities. It reconstructs HetGAT, compares ROMA and closer generalization baselines, proves limited architectural properties, identifies observability and transfer limits, and proposes a controlled research protocol. It contains no trained-model results or algorithm implementation.
